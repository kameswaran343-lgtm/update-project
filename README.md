# MeiKural

MeiKural is a local-first Tirukkural quotation checker with browsing,
educational explanations, and memory quizzes.

The complete application source is in [`MeiKural/`](./MeiKural/). See its
[README](./MeiKural/README.md) for project details, setup, and run instructions.

To start the development stack from the application directory, use:

```powershell
Set-Location .\MeiKural
corepack pnpm install
corepack pnpm dev
```
